## 📖 Sobre o Projeto

O **Sistema Inteligente de Localização de Jazigos** foi desenvolvido para facilitar a localização de sepulturas dentro de cemitérios de forma rápida e intuitiva.

Ao chegar ao cemitério, o visitante escaneia um **QR Code** localizado na entrada, sendo direcionado automaticamente para uma plataforma web.

No sistema, basta pesquisar o nome da pessoa desejada para visualizar:

- 📋 Informações do falecido
- 🪦 Localização exata do jazigo
- 🗺️ Mini mapa interativo
- 📍 Navegação guiada até o local

O objetivo é tornar a visita mais acessível, reduzindo dificuldades na localização de jazigos em grandes áreas cemiteriais.

---

## 🚀 Funcionalidades

✅ Leitura de QR Code na entrada do cemitério

✅ Acesso instantâneo ao sistema web

✅ Pesquisa de falecidos por nome

✅ Exibição dos dados cadastrados

✅ Visualização da posição do jazigo

✅ Mini GPS para orientação do visitante

✅ Interface simples e intuitiva
